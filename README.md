# AI-Based Enterprise Network Security Monitoring System

An AI-powered Enterprise Security Operations Center (SOC) dashboard designed to monitor enterprise network infrastructure, security events, alerts, and potential threats.

## 🚀 Project Overview

The system provides centralized visibility into enterprise network security through an interactive Streamlit dashboard.

It combines network monitoring, security log analysis, alert management, machine learning-based anomaly detection, and automated security reporting into a single platform.

## ✨ Features

- 📊 Enterprise Security Operations Dashboard
- 🌐 Enterprise Network Monitoring
- 💻 Device Inventory and Device Details
- 📜 Real-Time Security Log Monitoring
- 🚨 Security Alert Detection and Management
- 🤖 Machine Learning-Based Security Analysis
- 🧠 AI Security Copilot
- 🎯 MITRE ATT&CK Threat Mapping
- 🔍 Threat and Anomaly Analysis
- 📈 Security Statistics and Visualizations
- 📄 Automated Enterprise Security PDF Reports
- 📥 CSV Export for Security Logs and Device Inventory
- ⚡ Simulated Security Event Generation

## 🤖 AI / Machine Learning

The AI Security Copilot analyzes available enterprise security logs using a machine learning model.

The system provides:

- Anomaly detection
- ML prediction
- Confidence score
- Threat assessment
- Security event analysis
- Recommended security actions
- MITRE ATT&CK mapping

Security logs are processed through the ML analysis module and the results are displayed through the AI Security Copilot.
